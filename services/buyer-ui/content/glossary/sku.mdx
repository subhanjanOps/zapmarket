A **Stock Keeping Unit (SKU)** is a unique alphanumeric code assigned to a specific product variant. Each combination of attributes (size, color, configuration) gets its own SKU so inventory can be tracked precisely. When you select a variant and add it to cart, the SKU tells the system exactly which item to reserve and ship.
