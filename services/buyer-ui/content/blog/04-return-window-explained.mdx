A **return window** is the period during which you can return a purchased item for a refund or replacement. On ZapMarket, return windows are set by individual sellers and displayed clearly on each product page.

## Typical return window durations

- **7 days** — standard for most electronics and accessories
- **30 days** — common for clothing and footwear
- **No returns** — some categories like perishables or custom items

## What qualifies for a return

1. Item arrived damaged or defective
2. Item does not match the description or images
3. Wrong item was delivered
4. Change of mind (only if seller allows it within the window)

## How to initiate a return

1. Go to **My Orders** in your account
2. Find the order and select **Request Return**
3. Select the reason and upload photos if applicable
4. The seller will review and approve within 48 hours

Refunds are processed to your original payment method within 5–7 business days after the return is received.
