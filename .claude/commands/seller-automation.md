You are operating as three independent browser agents in parallel.

OBJECTIVE
Create and populate three seller accounts in the application through the UI.

AGENT ASSIGNMENTS

Agent 1
- Create Seller Account #1
- Use a realistic human first name and last name.
- Generate a valid email address matching the seller name.
- Complete all required onboarding fields.

Agent 2
- Create Seller Account #2
- Use a different realistic human first name and last name.
- Generate a valid email address matching the seller name.
- Complete all required onboarding fields.

Agent 3
- Create Seller Account #3
- Use a different realistic human first name and last name.
- Generate a valid email address matching the seller name.
- Complete all required onboarding fields.

SELLER REQUIREMENTS
- All seller names must be unique.
- All email addresses must be unique.
- Use realistic business information where required.
- Do not reuse data across sellers.
- Record seller credentials and profile details in the final report.

PRODUCT CREATION REQUIREMENTS

Each seller must create at least 30 products through the UI.

Target:
- Seller 1: 30+ products
- Seller 2: 30+ products
- Seller 3: 30+ products

Total expected products: Minimum 90

CATEGORY DISTRIBUTION
Randomly distribute products across multiple categories such as:
- Electronics
- Fashion
- Home & Kitchen
- Sports & Fitness
- Beauty & Personal Care
- Books
- Toys & Games
- Pet Supplies
- Office Supplies
- Automotive

PRODUCT CONTENT REQUIREMENTS

For every product:
- Create a realistic product title.
- Create a detailed product description.
- Create a short description if supported.
- Generate realistic pricing.
- Generate SKU values.
- Generate stock quantities.
- Populate all required fields.
- Ensure product information looks realistic and production-like.

IMAGE REQUIREMENTS

For every product:
- Upload at least one image through the UI.
- Use generated or sourced placeholder product images appropriate to the category.
- Verify image upload completed successfully.
- Do not leave products without images.

VALIDATION

After creating each product:
- Confirm it appears in the product listing.
- Confirm title is displayed correctly.
- Confirm description is saved.
- Confirm image is visible.
- Confirm seller ownership is correct.

ERROR HANDLING

If any step fails:
- Retry up to 3 times.
- Refresh the page if necessary.
- Re-authenticate if the session expires.
- Log failures with screenshots and details.
- Continue processing remaining products whenever possible.

FINAL REPORT

Return:
1. All seller names and email addresses.
2. Number of products created per seller.
3. Categories used.
4. Any failures encountered.
5. Screenshots of seller dashboards.
6. Screenshots of sample product pages.
7. Confirmation that every product contains descriptions and images.

SUCCESS CRITERIA

The task is complete only when:
- 3 seller accounts exist.
- Each seller has at least 30 products.
- Every product has a description.
- Every product has at least one image.
- Products are visible in the UI.
- A final validation report is produced.
