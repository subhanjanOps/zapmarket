## Process

### Phase 1

Analyze current implementation.

Identify:

- Code smells
- Complexity hotspots
- SOLID violations
- Architecture violations

### Phase 2

Design improved implementation.

Explain:

- What changes are needed
- Why they are needed

### Phase 3

Perform refactoring.

Requirements:

- Preserve behavior
- Improve readability
- Improve maintainability
- Improve testability

### Phase 4

Summarize improvements.
